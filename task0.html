Task 0: Navigation Bar

This task demonstrates a Flexbox-based navigation bar with the logo aligned to the left and navigation links to the right. All items are vertically centered using align-items: center.

How it works

  • The header container uses display: flex
  • justify-content: space-between places the logo on the left and links on the right
  • align-items: center vertically centers all items
  • gap applies consistent spacing between links
