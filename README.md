# Assignment #2 — Advanced CSS (Flexbox & Grid)

## Description

This project demonstrates advanced CSS layout techniques using **Flexbox** and **CSS Grid**. It includes five tasks covering navigation bars, card layouts, grid-based page layouts, image galleries, and a combined portfolio page.

## Structure

- **Task 0** — Navigation Bar (Flexbox)
- **Task 1** — Card Row (Flexbox)
- **Task 2** — Page Layout with Grid Areas (CSS Grid)
- **Task 3** — Image Gallery (CSS Grid)
- **Task 4** — Portfolio Page (Flexbox + Grid)

## How to Run

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open `index.html` in a browser, or visit the published GitHub Pages link.

## Technologies

- HTML5
- CSS3 (Flexbox, Grid)
